# Auvik Kumar Biswas: Portfolio

Live site: **https://auvikk.github.io**

A single-page portfolio for Auvik Kumar Biswas, a Computer Science (Real-Time Interactive Simulation) student at DigiPen Institute of Technology Singapore, in a joint degree with the Singapore Institute of Technology. It is hand-written HTML, CSS and JavaScript, hosted on GitHub Pages.

## What is on the site

- **Projects:** PinPoint (BowlEye), a bowling-form coaching app with pose detection, a Go backend and CI/CD; Stretch, a 2D grapple platformer with a from-scratch physics and collision engine in C++; N Fighters, a fighting game with an N-gram adaptive AI; and Dodge, a C++ ball-physics arena game.
- **Playground:** a small A* pathfinding lab you can use in the browser. Draw walls, drag the start and goal, switch between five heuristics (Octile, Euclidean, Chebyshev, Manhattan, Dijkstra) and watch how many cells each one explores. It is written in JavaScript for the page; the coursework version is in C++.
- **Journey:** education, leadership and work history.

## Run it locally

No build step. Clone the repo and open `index.html` in a browser.
